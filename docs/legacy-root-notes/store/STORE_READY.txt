🐛 TROUBLESHOOTING:

  Store tab not showing?
    → Refresh browser (Cmd+Shift+R on Mac)
    → Verify frontend running: http://localhost:3000

  Items not loading?
    → Verify backend running: http://localhost:8000
    → Check browser console for errors (F12)

  Purchase button not working?
    → Check you have enough balance
    → Check browser network tab for API errors
    → Verify backend is responding

  Need to restart?
    Backend:  uvicorn main:app --reload --host 127.0.0.1 --port 8000
    Frontend: npm run dev (in life-sprint-frontend folder)
