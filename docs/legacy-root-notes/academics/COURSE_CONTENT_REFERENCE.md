## Key Features of Course Content

### Brief Info Pop-Up Data
Each course in the curriculum has:
- **Description**: High-level overview of what the course covers
- **Skills**: Key skills developed
- **Real-World**: Practical applications and career relevance
- **Topics**: Detailed topic list from course_content.py
- **Learning Outcomes**: What students will achieve

### Quiz Structure
All quizzes follow a consistent format:
- **Text-based answers**: correct_answer is an exact string from options array
- **Passing score**: 70% required
- **Question components**: id, question, options[], correct_answer, explanation
- **Difficulty levels**: beginner, intermediate, advanced, very_high

### Content Alignment
- Quiz questions directly aligned with course descriptions
- Topics reflect the course's core learning areas
- Lessons provide structured content delivery
- Learning outcomes summarize skills gained

## Notes for Frontend Integration

The frontend should:
1. Fetch course description from `/api/curriculum/{major}/semester/{semester_num}` endpoint
2. Display course info in a modal/popup when player hovers or clicks
3. Show: name, description, skills, real_world value from curriculum data
4. Fetch quiz content from course_content.py via `/api/exams/course/{course_id}/quizzes` endpoint
5. Present quizzes with the GameBoard quiz modal component
6. Compare user's selected option text with question.correct_answer (both strings)
7. Calculate score as (correct_count / total_questions) * 100
8. Pass if score >= 70
