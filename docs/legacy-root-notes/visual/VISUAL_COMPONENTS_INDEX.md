## 🚀 Usage Patterns

### Pattern 1: Using GameLayout (Full Game)
```tsx
import { GameLayout } from './components'

<GameLayout
  playerName={player.name}
  age={player.age}
  year={2024}
  stats={playerStats}
  finance={playerFinance}
/>
```
See: [COMPONENTS.md](life-sprint-frontend/COMPONENTS.md) - GameLayout section

### Pattern 2: Individual Components
```tsx
import { CharacterCard, FinancialDashboard } from './components'

<CharacterCard name="Alex" stats={stats} />
<FinancialDashboard data={finance} />
```
See: [COMPONENTS.md](life-sprint-frontend/COMPONENTS.md) - Each component section

### Pattern 3: Backend Integration
```tsx
// Fetch data from API
const player = await api.get('/api/players/me')

// Transform for components
const stats = transformPlayerStats(player)

// Render with data
<GameLayout playerName={player.name} stats={stats} ... />
```
See: [GameExample.tsx](life-sprint-frontend/src/examples/GameExample.tsx)
